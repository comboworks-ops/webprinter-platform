# Webprinter 3D sales-folder review assets

This directory contains 20 AI-generated 3D review renders derived from the
approved `v1` structural diagrams. The existing `v1` SVG/PNG assets are kept
unchanged.

## Visual contract

- Pure white background for storefront compatibility.
- White coated cardboard with restrained Webprinter-blue physical flaps,
  tongues, and edge accents.
- No supplier branding, logos, text, documents, people, or decorative props.
- Each file preserves the corresponding model's panel count, bottom flaps,
  side flap, window, or closure mechanism.
- These files are review assets and are not wired into the live product until
  explicitly approved.

## Generation method

Built-in image generation was used in two stages for each asset:

1. Sketch-to-render generation using the corresponding `v1/png/master` image
   as authoritative geometry and a shared Webprinter 3D style anchor.
2. A background-only edit replacing the generated checkerboard backdrop with
   a uniform white studio background while retaining the product construction.

The A4, A5, A6, DIN-lang/M65, and 21 x 21 cm filenames map one-to-one to the
existing approved model keys.
